# MobileTrafficGeneration

跨城市网格通信流量预测与生成的研究代码。

当前工作四的目标是：在源城市学习卫星图像或 POI 与周流量的关系，在目标城市不使用流量观测进行训练、适配或选模，输出完整一周的网格流量曲线。

## 当前发布内容

`work4/` 是已审阅的代码快照，保留原实验相对目录及文件哈希：

- 普通条件流匹配（CFM）基线和合成检查。
- 源经验分布、Ridge 残差重采样对照的历史实验代码。
- 源高斯先验 CFM、四个源空间划分、坐标/卫星条件消融的训练核心。
- CRPS、覆盖率、曲线均值误差和时间结构评价函数。
- 纯代数目标函数检查。

目前公开的是基础实验代码；地理上下文校准候选尚未实现。现有模型输入为预提取的 130 维条件（2 维坐标 + 128 维卫星特征），尚不包含 POI 分支或原始图像编码器。

## 安装与合成检查

建议 Python 3.9 或以上。安装适合本机平台的 PyTorch 和 NumPy：

```bash
python -m pip install -r requirements.txt
python tools/run_checks.py
```

检查在临时目录运行，只生成合成数据，使用 CPU，不启动服务器训练。Linux GPU 启动器依赖 `fcntl` 与 `nvidia-smi`，Windows 合成检查不执行启动器。

## 实验使用边界

历史实验输出为 168 小时归一化 profile（call-in / call-out），不能直接解释为绝对流量。四个源空间划分不等于四个城市；同一模型的三个采样种子不等于三个训练种子。

历史结果表明随机划分下的收益未稳定保留到空间隔离评测；完整条件可能劣于简单源经验分布，卫星条件与 Ridge 残差对照接近。仓库不宣称新方法已得到验证或全面领先。

本仓库不提供私有原始数据、特征包、模型权重、服务器访问配置、未公开稿件或其他任务材料。`SOURCE_MANIFEST.json` 记录公开代码的来源和 SHA-256。

训练脚本保留原来的数据包和封存文件检查，因此不能在缺少相应输入时直接重跑历史实验。所需输入契约见 [work4/README.md](work4/README.md)。历史冻结协议保持原文，其冻结状态字段不是当前运行状态。所有配置及预测应在读取评价标签前封存；不得依据已开放目标评测调参。
